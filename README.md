### 🏦 [Moon Bank](https://github.com/praveenKavali/MoonBank) — Banking Backend

A secure, end-to-end banking backend covering account management, fund transfers, and transaction history.

- 🔌 **19 RESTful endpoints** built with Java / Spring Boot
- 🔐 Secured with **Spring Security, JWT, and role-based access control**
- ⏰ Automated **monthly interest calculation** via a Cron-scheduled Spring Scheduler job
- 🗃️ Normalized **PostgreSQL** schema modeled with JPA / Hibernate for data integrity
- 🧪 **85 unit tests** (JUnit + Mockito) covering critical banking workflows and edge cases

### ✅ [Moon Task](https://github.com/praveenKavali/MoonTask) — Full-Stack Task Manager

A responsive, production-style task management app with a Spring Boot API and a React frontend.

- 🔌 **13 RESTful endpoints** paired with a **React** UI
- 🎯 Custom **Spring AOP `@Aspect`** with `@After` advice to send login notification emails, keeping cross-cutting concerns out of core logic
- ⚡ **Redis caching** and **debounced search** to reduce database round-trips
- 🐳 Fully containerized with **Docker Compose** for single-command, CI-ready deployment
- 🧪 **55 unit tests** (JUnit + Mockito) covering task filtering, state transitions, and persistence
